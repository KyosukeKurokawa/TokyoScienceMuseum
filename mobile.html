Questions

Why is the viewport meta tag important?

It controls a webpage's scaling and dimensions on mobile devices to ensure proper responsive rendering.

How can you adjust the CSS for printing?

I use @media print queries within a stylesheet or link a separate stylesheet using the media="print" attribute.

When would you want to adjust the CSS for printing?

I use it to remove non-essential elements like navigation bars and sidebars, optimize layout, and save ink when users print physical pages.

Questions 2

Why do we need a viewport meta tag?

People need a viewport meta tag to instruct mobile browsers on how to control a page's dimensions and scaling so that it renders at the correct scale rather than defaulting to a zoomed out desktop view.

When you select the same tag twice, and in one of them you say "flex-direction: column;" and the other says "flex-direction: row;", which one takes priority?

The rule that appears later in the stylesheet takes priority due to the cascade, assuming both selectors have equal specificity.

How do you change the CSS for a web page displayed on a phone?

I change CSS for phones by using CSS media queries to apply specific styles when the screen size matches mobile dimensions.

Pick a website you use on your phone. Name two things it changes on mobile compared to desktop.

On mobile, YouTube replaces the multi-column desktop layout with a single-column feed and shifts the main navigation sidebar to a bottom tab bar.

What width did you choose for your breakpoint, and why?

A breakpoint of 760px is commonly chosen because it effectively marks the threshold where screens transition from tablet and desktop sizes down to mobile devices.
